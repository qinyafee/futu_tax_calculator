验证股票拆股/合股（公司行动）的处理：

- 拆股/合股行：`买卖方向` 填 `拆股` 或 `合股`，`数量` 填拆合股倍率（如 2 表示 1 拆 2；0.5 表示 2 合 1），不会产生盈亏，只会调整持仓数量、保持成本/卖空收入不变。
- US.SPLT：先买入100股@10，拆股×2后持仓200股，随后卖出200股@6，成本应变为5，利润200。
- US.RSPL：先买入100股@10，合股×0.5后持仓50股，随后卖出50股@22，成本应变为20，利润100。
- US.SSHT：先卖空100股@10，拆股×2后空头200股，随后买入平仓200股@4，平均卖空收入应变为5，利润200。
